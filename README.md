# atpd (Rust rewrite)

Rust rewrite of the [ATPD](https://github.com/atpd-project/atpd) control daemon.

Spec: [`RUST_REWRITE_PLAN.md`](https://github.com/atpd-project/atpd/blob/dev/RUST_REWRITE_PLAN.md) in the atpd repo.

```sh
cargo build --release --target aarch64-linux-android
```

The release binary is named `atpd`.
